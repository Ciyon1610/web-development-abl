# Web Development Activity-Based Learning

Three beginner-friendly static website activities, each in its own folder with an `index.html` page and `style.css` stylesheet.

- [College Information](college-information/index.html)
- [Food Ordering](food-ordering/index.html)
- [Bakery](bakery/index.html)

Open each page in a browser. The food menu is illustrative and does not accept real orders.

Concepts: semantic HTML, links, lists, typography, colors, spacing, CSS Grid, and responsive media queries.
